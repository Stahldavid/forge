### 1.1 Shared identifier lookup and representation mapping

All identifier-keyed read sets below resolve through D.getOwn in A/C/R/HC/HR/L.
Mutable dynamic writes use D.setOwn; computed-property literals, spreads and
Object.fromEntries retain their own-data semantics. See design section 3.1 and
S12-DEC-011. Schema still admits all non-empty strings, including Object.prototype names.
An inherited value is absent, not authority. Clone/restore does not remove that requirement.
Missing-ID error codes remain operation-specific; only the four tested missing-target
operations claim E-F02's exact AF_NOT_FOUND live / AF_INVALID_EVENT replay coverage.
J/P/AD Map/Set indexes and K/V behavior are unchanged. Evidence below supplements source
mapping; synthetic complete traces do not prove every missing-ID/error-order permutation.
