## 1. What the evidence means

This is the S1.1 obligation catalog, per-invariant matrix and divergence register required
by the adopted [scope/gate](S1.1_SCOPE_AND_GATE.md) and
[conformance plan](S1.1_CONFORMANCE_PLAN.md). It does not reopen P0a acceptance or claim
that newly added vectors existed at the earlier acceptance SHA.

`COVERED` means the stated applicable obligation has positive and negative executable
evidence, including the referenced replay composition. It does not mean exhaustive proof
over all inputs. `STRUCTURAL_ONLY` applies to contract separation; `ASSUMPTION` applies
to trusted inputs that synthetic tests cannot authenticate; `DIRECTION_ONLY` preserves
future architecture. `NOT_APPLICABLE` marks a field such as replay of a pure helper, not
a waiver for a testable obligation. Any unresolved testable obligation must be `PARTIAL`
or `BLOCKING_GAP` and block adoption under G-09.

No runtime/source/schema or historical P0a test is changed by this candidate. The only
dependency addition is exact development dependency `ajv@8.20.0`, compiling the repository's
real Draft 2020-12 schema for parity tests without coercion/defaults. No runtime schema
engine or generic conformance runner is introduced.

## 3. Normalized per-rule obligation catalog

This catalog uses a normalized record to avoid duplicating normative prose:

```text
rule_id = operation_id = catalog ID
invariants[] = K operation's explicit invariant list (also indexed individually in section 4)
applicability = accepted P0a public control path under K section 1 trust assumptions,
                except pure helper/composition/structural qualifications in this row
normative_summary, implementation_refs, positive_vectors, negative_vectors = row below
replay_vectors = TRACE + SEMANTIC for every persisted operation;
                 pure/guard/helper rows state their alternate or NOT_APPLICABLE
expected_protocol_result, error_or_reason_code = row + K exact rejection/retry table
coverage_status = COVERED unless explicitly qualified
divergence_status = NO_DIVERGENCE except DVG IDs below
notes = row qualifications and referenced K record
```

source names below are under `src/forge/agent-fabric/`; `HC` means public
`hardened-conductor.ts`, `HR` means `hardened-reducer.ts`, `C`/`R` are their inner components
`conductor.ts`/`reducer.ts`. They identify implementation evidence, not an alternative public
